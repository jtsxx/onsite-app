# OnSite

Two-sided technician marketplace PWA.

## Install on a phone
1. Open the live site (GitHub Pages or any static host).
2. iPhone: Safari → Share → Add to Home Screen.
3. Android: Chrome → Install app.

## What this build includes
- Customer: browse trades, request a visit, track job status
- Technician: profile, accept jobs, On my way → Arrived → Complete
- Installable PWA (offline shell)
- Call-out + hourly shown before booking

## What is still required to take real paid jobs
1. Hosting
2. Backend so two phones share jobs
3. Stripe
4. Real licensed techs + insurance
5. Legal terms
